# [실습과제02] 모바일/웹서비스프로젝트

Markdown은 간단한 문법으로 문서를 작성할 수 있는 경량 마크업 언어입니다.  
GitHub의 `README.md` 작성에 많이 사용됩니다.

---

## 1. 제목

`#`의 개수에 따라 제목의 크기를 정할 수 있습니다.

```markdown
# 제목 1
## 제목 2
### 제목 3
```
